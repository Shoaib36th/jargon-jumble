# 🔤 Jargon Jumble — A Tech-Themed Word Scramble Game

A fun, terminal-based word scramble game packed with tech humor, coding jargon, and workplace jokes. Test your developer vocabulary, solve scrambled words, use context hints, and aim for a flawless score!

---

## 🌟 Features

- **Tech Humor & Jargon:** Words and context hints tailored for developers, tech enthusiasts, and office workers.
- **Dynamic Word Scrambling:** Randomly shuffles letters for a unique experience each time you play.
- **Interactive Game Commands:**
  - Ask for a **`hint`** to get a funny fill-in-the-blank context sentence.
  - Type **`skip`** to pass a tough word and see the correct answer.
  - Type **`quit`** to exit the game early.
- **Score Tracking & Performance Rating:** Tracks your score across 5 rounds and provides customized feedback based on your final result.

---

## 🚀 How It Works

1. The game selects 5 unique words at random from the tech word bank.
2. For each round, the word is scrambled and presented in UPPERCASE.
3. You can guess the word, request a contextual hint, skip the turn, or quit.
4. After 5 rounds, your final score is displayed along with developer-themed feedback!
